The optional `GET /api/rea/status` route reports a **discovery-only** status for an already-installed REA CLI. It calls MCP `initialize` and `tools/list`; it never opens targets or calls analysis tools. Configure `REA_BIN` to a trusted executable path. The default is `rea`. If REA is unavailable, the endpoint responds with a typed `unavailable` result rather than fake capability data. See `docs/rea-adapter.md`.
