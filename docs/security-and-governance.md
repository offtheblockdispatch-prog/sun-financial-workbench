# Security and Governance

This project is designed with strict operational boundaries.

## Guardrails

- no live trading without explicit approval
- no irreversible action without review
- no unbounded trust in autonomous suggestions
- clear attribution of upstream source and capabilities
- paper-first validation of strategy logic

## Evidence-first requirements

The platform should preserve:
- where a fact came from
- what was observed
- what was inferred
- what remains uncertain

## Safety boundaries

Important distinctions must remain visible:
- analysis vs execution
- simulation vs live
- source observation vs reconstructed claim
- human approval vs autonomous action

## Governance model

This repo is intended to operate under a transparent, principle-based governance standard: clear decisions, bounded authority, visible evidence, and human accountability.
