# REA Integration

The project is designed to respect the upstream REA (Reverse Engineer Anything) ecosystem without copying it or merging it into the workbench core.

## Relationship model

- REA remains an upstream capability provider
- SUN Financial Workbench uses REA as an engine or adapter layer
- evidence generated by REA remains attributed to its upstream source and process
- the workbench adds operational context, memory, and higher-level task orchestration

## Design intent

The workbench is a system that sits above analysis tools and turns them into a structured operating environment.

## Integration goals

- provider-neutral contracts
- explicit evidence provenance
- source and binary fact separation
- capability discovery with version tracking
- safe, reviewable execution boundaries

## Operational boundary

REA is useful for:
- program analysis
- binary structure understanding
- symbol and function tracing
- issue discovery and evidence capture

The workbench adds:
- memory graphs
- financial simulation
- execution planning
- operator-facing summaries
- risk-aware action controls

## Principle

The workbench does not claim to replace REA. It creates a broader system for investigations, strategy, and action that REA can help power.
